Entry for the make.fun bounty **"Make the AI judge feel curious"**
(make-the-ai-judge-feel-curious-20261122-2311).

## What it does

`main.py` (Python 3.13, no network) writes one short intriguing text to
`/output/entry.txt` — 271 characters.

## The idea

The text hides a real secret in plain sight: the first letter of each
sentence spells **CURIOUS**. The reader is invited to find it, so the
curiosity pays off on a second reading instead of ending in an empty
promise.

> Close your eyes — the words are still here. Until you read on, you won't
> know why. Read the beginnings; each one is a door. Inside this text hides
> a message for you. Only the first letters know it. Unless you look, you'll
> never see it. So — what did curiosity just spell?

## Run it

```sh
python3 main.py   # writes /output/entry.txt
```
